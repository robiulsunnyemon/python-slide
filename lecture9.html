Code Organization

Python Modules & Clean Import Patterns

A module is simply any .py file; a package is a folder of modules:

import_styles.py
# 1. Standard Module Import
import math
print(math.sqrt(16))  # 4.0

# 2. Specific Item Import
from datetime import datetime, timedelta
now = datetime.now()

# 3. Aliased Import
import pathlib as pl

# ❌ Dangerous Anti-Pattern: Namespace Pollution!
# from math import *  (NEVER use in production!)

Why Wildcard Imports (*) are Banned:

from module import * dumps hundreds of unknown variables into your global namespace. If two modules define a function named open() or calc(), one will silently overwrite the other, creating hidden runtime bugs!

Execution Guard

The if __name__ == "__main__": Guard

Distinguish between running a file directly as a script versus importing it as a library module:

math_utils.py
def add_tax(amount: float, rate=0.15) -> float:
    return amount * (1 + rate)

# This block ONLY executes when running: python math_utils.py
# It will NOT run when imported by another file!
if __name__ == "__main__":
    print("Running self-test...")
    test_result = add_tax(100)
    print(f"Test Passed: {test_result == 115.0}")

How Python Sets __name__:

  • Direct Run (CLI): Python assigns __name__ = "__main__".
  • Imported via import: Python sets __name__ = "math_utils" (file basename).
  • Key Advantage: Enables files to act both as reusable modules AND standalone CLI scripts!
Isolation Architecture

Virtual Environments & Dependency Locking

Isolate project dependencies so different projects never suffer package version collisions:

1. Terminal Workflow (venv creation):

# 1. Create a virtual environment (.venv)
python -m venv .venv

# 2. Activate on Windows PowerShell:
.\.venv\Scripts\Activate.ps1

# 2b. Activate on macOS/Linux:
source .venv/bin/activate

2. Dependency Pinning with pip:

# Install a package:
pip install requests

# Freeze exact dependencies to file:
pip freeze > requirements.txt

# Teammate reproduces identical environment:
pip install -r requirements.txt
Standard Library

Standard Library: pathlib, sys & datetime

Python comes with "batteries included" — powerful built-in toolkits requiring zero installation:

stdlib_demo.py
import sys
from pathlib import Path
from datetime import datetime

# Modern Pathlib (Cross-platform path handling)
data_dir = Path("storage") / "logs"
data_dir.mkdir(parents=True, exist_ok=True)

# Timestamp Formatting
timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
print(f"[{timestamp}] OS Platform: {sys.platform}")

# CLI Arguments: python script.py arg1 arg2
print(f"CLI Arguments Passed: {sys.argv}")

Batteries Included Highlights:

  • pathlib.Path: Modern object-oriented path manipulation
  • sys.argv: Command-line argument vector list
  • datetime.strftime(): Format timestamps into clean strings
  • secrets: Cryptographically secure tokens & random passwords
Pitfalls

4 Common Module & Package Pitfalls ⚠️

Avoid these four frequent architectural and virtual environment mistakes:

❌ 1. Naming File Same as Module

Naming file "math.py" or "random.py"
Shadows Python's built-in module → crashes!

❌ 2. Circular Imports

A.py imports B.py, and B.py imports A.py
Fix: Restructure shared logic into utils.py

❌ 3. Committing .venv to Git

Uploading thousands of venv binary files!
Fix: Always add .venv/ to .gitignore

❌ 4. Installing Globally Without venv

Pollutes system Python & breaks OS packages.
Fix: Always verify active (.venv) prompt!

Applied Project

Mini-Project: Automated CLI Log & File Sorter

A modular system utility sorting files by extension and logging timestamps with pathlib:

cleaner_cli.py
import sys
from pathlib import Path
from datetime import datetime

def scan_directory(target_path: str):
    folder = Path(target_path)
    if not folder.exists():
        print(f"❌ Error: {target_path} not found.")
        return

    files = [f.name for f in folder.iterdir() if f.is_file()]
    now = datetime.now().strftime("%H:%M:%S")
    print(f"[{now}] Scanned {len(files)} files in '{target_path}'")

if __name__ == "__main__":
    target = sys.argv[1] if len(sys.argv) > 1 else "."
    scan_directory(target)

Modular Production Architecture:

This script can be called from command line (python cleaner_cli.py ./downloads) or imported seamlessly inside an automated Celery background worker without executing CLI parsing!
