Standard Packaging

Modern Project Layout & pyproject.toml

PEP 621 standardized packaging replaces legacy setup.py with unified declarative metadata:

pyproject.toml
[project]
name = "taskpulse"
version = "1.0.0"
description = "Enterprise Task & Telemetry CLI"
authors = [{name = "Robiul Suny Emon", email = "robiul@example.com"}]
requires-python = ">=3.12"
dependencies = [
    "requests>=2.31.0",
    "python-dotenv>=1.0.0"
]

# Expose global command in terminal
[project.scripts]
taskpulse = "taskpulse.cli:main"

[build-system]
requires = ["setuptools>=68.0"]
build-backend = "setuptools.build_meta"

Quality Assurance

Automated Unit Testing with pytest

Write maintainable, robust test suites to ensure zero regressions in production code:

tests/test_engine.py
import pytest
from taskpulse.core import Task, TaskManager

# Pytest Fixture (Reusable test setup)
@pytest.fixture
def empty_manager():
    return TaskManager()

def test_add_task(empty_manager):
    task = empty_manager.add("Build API", priority=1)
    assert task.title == "Build API"
    assert len(empty_manager.list_all()) == 1

def test_invalid_priority_raises(empty_manager):
    with pytest.raises(ValueError):
        empty_manager.add("Bad Task", priority=-5)

Running Pytest in Terminal:

pytest -v → Verbose test runner
pytest --cov=src → Code coverage report
pytest -k "priority" → Run specific tests
Containerization

Production Docker Containerization

Package your Python app, dependencies, and runtime into an immutable, portable Docker container:

Dockerfile
# Stage 1: Official Lightweight Python Base
FROM python:3.12-slim

# Prevent python from buffering stdout/stderr
ENV PYTHONUNBUFFERED=1

WORKDIR /app

# Install project dependencies
COPY pyproject.toml .
RUN pip install --no-cache-dir .

# Copy application source code
COPY src/ ./src/

# Create non-root security user
RUN useradd -u 8888 appuser && chown -R appuser /app
USER appuser

ENTRYPOINT ["taskpulse"]

Docker CLI Commands:

docker build -t taskpulse:1.0 .
docker run --rm taskpulse:1.0 list
Runs identically on Mac, Windows & Linux Cloud!

Pitfalls

4 Production Release Traps ⚠️

Watch out for these critical packaging and deployment mistakes:

❌ 1. Running Docker as Root

Huge security vulnerability!
Fix: Always add USER appuser in Dockerfile.

❌ 2. Missing .dockerignore

Copying .venv, __pycache__, and .git into container bloats image sizes by 500+ MB!

❌ 3. Floating Dependency Versions

Unpinned dependencies cause breaking builds on upstream library updates.

❌ 4. Testing without Virtualenv Isolation

Tests pass locally because of global packages, but fail in CI/CD pipelines!
