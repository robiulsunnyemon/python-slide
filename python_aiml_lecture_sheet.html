Phase 1 — Python Core Foundations & Algorithmic Thinking

Classes 01 to 05 • Build a solid programming base, OOP structures, error handling, and environment isolation.

Class 01
Python Fundamentals & Environment Setup
Topic 1 — Ecosystem & VS Code Workflow
Python 3.12 installation, VS Code setup, virtual environment isolation (venv/conda), pip package manager, and script execution.
Topic 2 — Syntax, Variables & Primitive Types
Dynamic typing, numbers, strings, booleans, string formatting (f-strings), type casting, and standard I/O operations.
🎯 Home Task Problem
Set up a clean virtual environment and write an interactive CLI profile utility that processes inputs and displays metric summaries.
Class 02
Data Structures & Control Flow
Topic 1 — Control Flow & Branching
If/elif/else conditions, truthy/falsy evaluation, ternary operators, while/for loops, range, and loop controls (break, continue).
Topic 2 — Built-in Data Structures
Lists, Tuples, Sets, Dictionaries, sequence slicing, mutability vs immutability, lookup performance, and core methods.
🎯 Home Task Problem
Build a CLI Student Performance System that tracks student records, computes averages, and filters top performers.
Class 03
Functions, Modules & Functional Patterns
Topic 1 — Reusable Function Design
Defining functions, positional/keyword parameters, *args, **kwargs, return types, docstrings, type hinting, and variable scope.
Topic 2 — Functional Programming & Comprehensions
Lambda functions, map(), filter(), list/dict/set comprehensions, generator expressions, and custom package creation.
🎯 Home Task Problem
Create reusable math & string processing modules using list comprehensions and lambda filters to process nested dataset lists.
Class 04
Object-Oriented Programming (OOP)
Topic 1 — Classes, Objects & Encapsulation
Classes, __init__ constructor, instance vs class attributes, magic dunder methods (__str__, __repr__), private members, and @property.
Topic 2 — Inheritance & Polymorphism
Single/multiple inheritance, super(), method overriding, Abstract Base Classes (abc module), duck typing, and composition.
🎯 Home Task Problem
Design an OOP Banking System with Account, Customer, Transaction, and Bank classes with balance validation and transaction logs.
Class 05
File Handling, Exceptions & Packages
Topic 1 — File I/O & Serialization
Reading/writing TXT, CSV, JSON files, context managers ('with' statement), pathlib file operations, and JSON serialization.
Topic 2 — Exception Handling & Environment Isolation
Try/except/else/finally blocks, custom exception classes, requirements.txt management, and python-dotenv environment isolation.
🎯 Home Task Problem
Build a robust CSV Importer & JSON Generator that validates raw schema, handles exceptions safely, and logs error metrics.

Phase 2 — Data Science Foundations & Numerical Computing

Classes 06 to 10 • High-performance computing with NumPy, Pandas data wrangling, EDA visualization, statistics, and SQL.

Class 06
High-Performance Computing with NumPy
Topic 1 — NumPy Ndarrays & Vectorization
N-dimensional array creation, dtypes, reshaping, array slicing, broadcasting rules, and vectorized math vs Python loops.
Topic 2 — Matrix Math & Statistical Operations
Matrix multiplication (@), np.linalg operations, np.random sampling, boolean masking, and axis aggregations (mean, std, sum).
🎯 Home Task Problem
Build a financial portfolio risk simulator using vectorized NumPy arrays to compute covariance matrices and 1,000 Monte Carlo runs.
Class 07
Data Wrangling & Manipulation with Pandas
Topic 1 — DataFrames & Indexing
Series & DataFrames, loc/iloc indexing, boolean filtering, missing data treatment (fillna, dropna), and data type conversion.
Topic 2 — Groupby, Merging & Pivot Tables
Groupby aggregations, pivot tables, table merges (merge, concat, join), custom functions (.apply()), and datetime parsing.
🎯 Home Task Problem
Clean and merge a multi-table e-commerce dataset, handling missing values and aggregating revenue metrics per category.
Class 08
Data Visualization & Exploratory Data Analysis (EDA)
Topic 1 — Statistical Visualizations
Line plots, bar charts, histograms, KDE density plots, box plots, scatter plots, pair plots, and Seaborn heatmaps.
Topic 2 — Exploratory Data Analysis (EDA)
Detecting distribution skewness, feature correlation analysis, outlier detection, and drafting actionable data summary reports.
🎯 Home Task Problem
Perform complete EDA on a Telecom Churn dataset, generating 6 publication-ready charts and an executive insight summary.
Class 09
Applied Statistics & Probability for ML
Topic 1 — Descriptive & Inferential Statistics
Mean, median, mode, variance, std dev, Normal/Binomial distributions, Z-scores, and Central Limit Theorem (CLT).
Topic 2 — Hypothesis Testing & Correlation
Null/alternative hypotheses, p-values, t-tests, Chi-Square test, ANOVA, Pearson/Spearman correlation, and confidence intervals.
🎯 Home Task Problem
Conduct an A/B test analysis on e-commerce landing page conversion rates using SciPy, computing p-values and confidence intervals.
Class 10
Relational Databases, SQL & Python Integration
Topic 1 — SQL Queries & Schema Design
Tables, datatypes, PK/FK constraints, SELECT, WHERE, JOIN (INNER, LEFT), GROUP BY, HAVING, subqueries, and window functions.
Topic 2 — SQLAlchemy & Python Connectivity
Connecting Python to PostgreSQL via psycopg2/SQLAlchemy ORM models, session management, and querying into Pandas.
🎯 Home Task Problem
Build a Python script connecting to PostgreSQL, populate normalized sales tables, execute complex queries, and export DataFrames.

Phase 3 — Machine Learning Core & Predictive Modeling

Classes 11 to 15 • Scikit-Learn pipelines, regression, tree ensembles (XGBoost), clustering, and hyperparameter tuning.

Class 11
ML Workflow & Scikit-Learn Pipeline
Topic 1 — ML Formulation & Preprocessing
Supervised vs unsupervised learning, features/target, train_test_split, preventing data leakage, scaling, and categorical encoders.
Topic 2 — Scikit-Learn Estimators & Pipelines
Fit/transform/predict API, ColumnTransformer, multi-step Pipeline objects, and model serialization with joblib.
🎯 Home Task Problem
Build a production Scikit-Learn pipeline preprocessing mixed numerical/categorical data and serializing the model artifact.
Class 12
Supervised Learning I — Regression Models
Topic 1 — Linear, Ridge & Lasso Regression
Ordinary Least Squares math, gradient descent, cost functions, L1 (Lasso) vs L2 (Ridge) regularization, and feature selection.
Topic 2 — Regression Metrics & Residuals
MSE, RMSE, MAE, R-squared (R2), Adjusted R2, residual plots, homoscedasticity checks, and model evaluation metrics.
🎯 Home Task Problem
Develop a House Price Prediction model using regularized regression, analyze coefficient importances, and plot error residuals.
Class 13
Classification & Tree Ensemble Algorithms
Topic 1 — Classification Algorithms
Logistic Regression, Decision Trees, K-Nearest Neighbors (KNN), Naive Bayes, Support Vector Machines (SVM), decision boundaries.
Topic 2 — Random Forest, XGBoost & SMOTE
Bagging vs Boosting, Random Forests, XGBoost gradient boosting, feature importances, and SMOTE for imbalanced classes.
🎯 Home Task Problem
Train a Credit Risk Classifier using Random Forest & XGBoost, apply SMOTE class balancing, and plot ROC-AUC curves.
Class 14
Unsupervised Learning — Clustering & PCA
Topic 1 — Clustering Algorithms
K-Means clustering, distance metrics, Elbow Method, Silhouette scores, Hierarchical Clustering (Dendrograms), and DBSCAN.
Topic 2 — Dimensionality Reduction (PCA)
Principal Component Analysis (PCA) variance maximization, eigenvalues intuition, explained variance, and t-SNE / UMAP visualization.
🎯 Home Task Problem
Segment an e-commerce customer database using K-Means and PCA, visualizing customer clusters in 2D and detailing buyer personas.
Class 15
Model Evaluation & Hyperparameter Optimization
Topic 1 — Validation Strategies & Diagnostic Metrics
K-Fold & Stratified Cross-Validation, Confusion Matrix, Precision, Recall, F1-Score, Macro/Micro averages, and ROC-AUC.
Topic 2 — Hyperparameter Search & Optuna
GridSearchCV, RandomizedSearchCV, Bayesian Optimization using Optuna, hyperparameter search spaces, and overfitting prevention.
🎯 Home Task Problem
Optimize an XGBoost pipeline using Optuna and Stratified 5-Fold CV, generating full classification reports and ROC curves.

Phase 4 — Deep Learning, Neural Networks & Computer Vision

Classes 16 to 20 • PyTorch tensors, custom neural network training loops, OpenCV image processing, CNNs, and NLP.

Class 16
Deep Learning & PyTorch Core Tensors
Topic 1 — Perceptrons & PyTorch Tensors
Activation functions (ReLU, Sigmoid, Softmax), PyTorch tensor math, CUDA GPU acceleration, autograd automatic differentiation.
Topic 2 — Custom Dataset & DataLoader API
Subclassing torch.utils.data.Dataset, DataLoader mini-batching, shuffling, dataset splitting, and image transformations.
🎯 Home Task Problem
Write a custom PyTorch Dataset & DataLoader class, execute tensor math on GPU/CPU, and verify autograd gradient updates.
Class 17
Custom Neural Networks & Training Loops
Topic 1 — Building Custom nn.Module
Linear layers (nn.Linear), activations, dropout regularization (nn.Dropout), batch normalization, and forward pass execution.
Topic 2 — Complete Training & Evaluation Loop
Loss functions (CrossEntropyLoss), optimizers (AdamW, SGD), learning rate schedulers, evaluation loops, and model checkpointing.
🎯 Home Task Problem
Build and train an MLP image classifier on Fashion-MNIST in PyTorch, plotting loss/accuracy curves and saving best checkpoints.
Class 18
Computer Vision Essentials with OpenCV
Topic 1 — Image Processing Foundations
Color spaces (RGB, BGR, HSV), image resizing, cropping, rotation, affine transformations, thresholding, and morphological operations.
Topic 2 — Contours & Feature Detection
Sobel/Canny edge detection, finding contours (cv2.findContours), bounding boxes, histogram equalization, and object tracking.
🎯 Home Task Problem
Build an automated document scanner script in OpenCV that detects page edges, applies perspective warping, and crops scanned pages.
Class 19
CNNs & Transfer Learning
Topic 1 — CNN Architecture & Convolutions
nn.Conv2d, pooling layers (nn.MaxPool2d), stride, padding, receptive fields, and CNN feature map visualization.
Topic 2 — Transfer Learning Backbones
Fine-tuning ResNet50/EfficientNet with torchvision, frozen vs trainable weights, classification heads, and data augmentations.
🎯 Home Task Problem
Build an image classifier (e.g. leaf disease detector) using transfer learning with ResNet50 in PyTorch, achieving >90% test accuracy.
Class 20
NLP Fundamentals & Sequence Models
Topic 1 — Text Processing & Embeddings
Tokenization, lowercasing, stopword removal, TF-IDF, Word2Vec embeddings, and PyTorch nn.Embedding layers.
Topic 2 — RNNs, LSTMs & Transformer Attention
Recurrent neural networks, LSTMs, vanishing gradients, self-attention mechanism intuition, and Transformer architecture basics.
🎯 Home Task Problem
Train a sentiment analysis model using a PyTorch LSTM network on movie reviews, using custom tokenization and embeddings.

Phase 5 — Applied AI, Generative AI & LLMs

Classes 21 to 25 • Hugging Face Transformers, local Ollama execution, ChromaDB Vector Search, RAG, AI Agents & FastAPI.

Class 21
Hugging Face & Pretrained Transformers
Topic 1 — Hugging Face Hub & AutoModels
Loading pretrained LLMs (AutoModelForCausalLM), generation parameters (temperature, top_p), and Hugging Face pipelines.
Topic 2 — Fine-Tuning & Quantization
PEFT (Parameter-Efficient Fine-Tuning), LoRA/QLoRA adapters, 4-bit model quantization, and Hugging Face SFTTrainer.
🎯 Home Task Problem
Load an open-weights LLM (Llama-3-8B / Qwen-2.5) via Hugging Face, run text generation pipelines, and build a text summarizer.
Class 22
Local LLMs (Ollama) & Prompt Engineering
Topic 1 — Local LLM Execution with Ollama
Installing Ollama, pulling local models (Llama 3.2, Mistral, DeepSeek), Modelfiles, system prompts, and python SDK integration.
Topic 2 — Advanced Prompting & Structured JSON
Zero-shot, Few-shot, Chain-of-Thought (CoT), ReAct framework, system personas, and enforcing Pydantic JSON output schemas.
🎯 Home Task Problem
Build a local CLI Document Information Extractor powered by Ollama enforcing Pydantic JSON schema output for resume details.
Class 23
Retrieval-Augmented Generation (RAG) & Vector DBs
Topic 1 — Vector Embeddings & Similarity Search
Generating embeddings with sentence-transformers, Cosine similarity, Euclidean distance, HNSW indexing, and Vector DB architecture.
Topic 2 — RAG Pipelines with ChromaDB
Document loading (PDF, TXT), text chunking strategies (RecursiveCharacterTextSplitter), vector indexing into ChromaDB, and context RAG.
🎯 Home Task Problem
Build a complete Document Q&A RAG application that indexes multi-page PDFs into ChromaDB and answers questions with page citations.
Class 24
AI Agents & Workflows with LangChain
Topic 1 — LangChain Core Architecture
Chains (LLMChain), memory management (BufferMemory, VectorStoreMemory), document loaders, and output parsers.
Topic 2 — Autonomous AI Agents & Tool Calling
Defining custom Python tool functions, ReAct reasoning loops, multi-tool decision selection, error handling, and guardrails.
🎯 Home Task Problem
Build an autonomous AI Research Agent using LangChain that queries search tools, vector DBs, and compiles markdown reports.
Class 25
Serving AI Models with FastAPI Backend
Topic 1 — Modern FastAPI Architecture
Async handlers (async/await), Pydantic validation schemas, Dependency Injection (Depends), CORS middleware, and API Routers.
Topic 2 — Production REST APIs for AI
Streaming LLM responses (StreamingResponse / SSE), exception handlers, background tasks, and interactive Swagger OpenAPI docs.
🎯 Home Task Problem
Build a production FastAPI backend exposing endpoints for ML classification, vector search, and streaming LLM responses.
