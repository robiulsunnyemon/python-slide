Lexical Scope

First-Class Functions & Closures

A closure is an inner function that remembers variables from its enclosing lexical scope even after the outer function finishes executing:

closure_demo.py
def make_multiplier(factor: int):
    # Enclosed state retained in closure
    def multiply(number: int) -> int:
        return number * factor
    return multiply

# Factory generating customized functions
double = make_multiplier(2)
triple = make_multiplier(3)

print(double(10))  # 20
print(triple(10))  # 30

What Makes it a Closure?

  • 1. Must have a nested function (multiply inside make_multiplier).
  • 2. The nested function must reference a variable from enclosing scope (factor).
  • 3. The enclosing function must return the nested function object.
Metaprogramming

Custom Function Decorators & @wraps

A decorator dynamically enhances a function without modifying its underlying source code:

timer_decorator.py
import time
from functools import wraps

def timer_decorator(func):
    @wraps(func)  # Preserves original func name and docstring
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        duration = time.perf_counter() - start
        print(f"⏱️ [{func.__name__}] executed in {duration:.4f}s")
        return result
    return wrapper

@timer_decorator
def heavy_computation():
    return sum(i ** 2 for i in range(1_000_000))

heavy_computation()

Syntactic Sugar Explained:

Writing @timer_decorator above a function definition is exact identical syntactic sugar for:
heavy_computation = timer_decorator(heavy_computation)

Lazy Evaluation

Generators: Stream Processing with yield

Unlike lists that store everything in RAM, generators produce values one at a time on demand ($O(1)$ memory):

generator_demo.py
import sys

# 1. Standard List (Eager: Allocates 80+ MB of RAM!)
big_list = [x ** 2 for x in range(10_000_000)]

# 2. Generator Function (Lazy: Uses ONLY 200 Bytes!)
def generate_squares(limit: int):
    for x in range(limit):
        yield x ** 2

gen = generate_squares(10_000_000)

print(f"List RAM: {sys.getsizeof(big_list):,} bytes")
print(f"Gen  RAM: {sys.getsizeof(gen):,} bytes")

How yield Works:

When Python hits yield, it pauses execution and freezes local state. When next() is called again, execution resumes precisely where it left off!

Core Protocol

The Iteration Protocol: __iter__ & __next__

Understand what Python's for loop actually does behind the scenes:

custom_iterator.py
class CountDown:
    def __init__(self, start: int):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        val = self.current
        self.current -= 1
        return val

for n in CountDown(3):
    print(n)  # 3, 2, 1

Behind Every for Loop:

  1. 1. Calls iter(obj) to obtain an iterator object.
  2. 2. Repeatedly calls next(iterator) to get items.
  3. 3. Gracefully catches StopIteration to terminate.
Pitfalls

4 Common Functional Python Traps ⚠️

Watch out for these four advanced functional programming bugs:

❌ 1. Exhausting a Generator Stream

Generators are single-use streams!
Iterating a 2nd time yields NOTHING.

❌ 2. Forgetting @functools.wraps

func.__name__ becomes 'wrapper' instead of original func name!
Breaks introspection & logging.

❌ 3. Late Binding in Closures

funcs = [lambda: i for i in range(3)] → all return 2!
Fix: lambda i=i: i (bind default arg).

❌ 4. Decorator Missing return value

If wrapper forgot 'return result', original function returns None!

Production Engine

Mini-Project: Rate Limiter & Telemetry Decorator

A production-grade parameterized decorator preventing API spamming and recording performance:

rate_limiter.py
import time
from functools import wraps

def rate_limit(max_per_sec: int):
    min_interval = 1.0 / max_per_sec
    last_called = [0.0]  # Mutable closure state

    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            elapsed = time.time() - last_called[0]
            if elapsed < min_interval:
                time.sleep(min_interval - elapsed)
            last_called[0] = time.time()
            return func(*args, **kwargs)
        return wrapper
    return decorator

@rate_limit(max_per_sec=2)
def call_ai_api(prompt: str):
    print(f"🚀 API Call dispatched: '{prompt}'")

call_ai_api("Summarize PDF")

Decorator with Arguments Pattern:

A decorator with arguments is a 3-layer nested structure: Outer function accepts decorator configuration → Middle function accepts target function → Inner wrapper handles execution!
