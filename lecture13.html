Network Foundation

HTTP Verbs & Status Code Lifecycle

Every internet interaction relies on standardized HTTP verbs and response status codes:

Core HTTP Verbs:

GET → Read / Retrieve resource
POST → Create new resource with payload
PUT/PATCH → Update existing resource
DELETE → Destroy / Remove resource

Status Code Categories:

2xx Success → 200 OK, 201 Created
3xx Redirect → 301 Moved Permanently
4xx Client Error → 401 Auth, 404 Not Found, 429 Throttled
5xx Server Error → 500 Internal Error, 502 Bad Gateway
REST APIs

Consuming REST APIs with requests

Fetch real-time data, parse JSON, pass query parameters, and handle network timeouts:

api_consumer.py
import requests

url = "https://api.github.com/users/robiulsunyemon"
headers = {"User-Agent": "PythonApp/1.0"}

try:
    # Mandatory timeout to prevent hanging!
    response = requests.get(url, headers=headers, timeout=5.0)
    response.raise_for_status()  # Raises error if 4xx/5xx

    data = response.json()  # Auto-parse JSON into Python Dict
    print(f"User: {data['name']} | Repos: {data['public_repos']}")

except requests.exceptions.RequestException as e:
    print(f"⚠️ Network error: {e}")

Essential Best Practices:

  • 1. Always set timeout=5.0 to prevent frozen processes.
  • 2. Use response.raise_for_status() for instant status assertion.
  • 3. Store private API keys in .env with os.getenv()!
HTML Scraping

Web Scraping with BeautifulSoup4

Parse raw HTML DOM trees and extract structured data using intuitive CSS selectors:

scraper_demo.py
from bs4 import BeautifulSoup

html_doc = """
<div class="catalog">
    <div class="card">
        <h2 class="title">Python Masterclass</h2>
        <span class="price">$49.99</span>
        <a href="/course/py101">Enroll Now</a>
    </div>
</div>
"""

soup = BeautifulSoup(html_doc, "html.parser")

# Querying via CSS Selector
title = soup.select_one("h2.title").get_text(strip=True)
price = soup.select_one("span.price").get_text(strip=True)
link  = soup.select_one("a")["href"]

print(f"Product: {title} | Price: {price} | URL: {link}")

Key BeautifulSoup Methods:

  • soup.select_one(css) → First matching element
  • soup.select(css) → List of all matches
  • tag.get_text(strip=True) → Clean inner text
  • tag['attr'] → Access HTML attributes (e.g. href, src)
Scraping Ethics

Ethical Scraping, robots.txt & Headers

Protect target servers, avoid IP bans, and build respectful, sustainable scrapers:

1. Always Respect robots.txt

Visit https://target-site.com/robots.txt. Never scrape endpoints marked with Disallow: /private/.

2. Polite Crawl Delay

Insert time.sleep(random.uniform(1.0, 2.5)) between page requests to prevent overwhelming origin servers.

3. Custom User-Agent Header

Default python-requests/x.y headers get blocked by Cloudflare. Identify your app politely with standard browser headers.

4. Session & Connection Pooling

Use requests.Session() to reuse TCP connections, dramatically improving crawl performance and lowering network overhead.

Pitfalls

4 Common Web API & Scraping Traps ⚠️

Watch out for these high-frequency network engineering mistakes:

❌ 1. Leaking API Keys in GitHub

Hardcoding OPENAI_KEY = "sk-..." → Bot theft & huge bills!
Fix: Always load from .env with python-dotenv.

❌ 2. Scraping Dynamic JavaScript SPAs

requests only downloads static HTML (empty <div id="app">)!
Fix: Inspect Network Tab for underlying JSON API.

❌ 3. Missing Request Timeout

Without timeout=5.0, your app will hang indefinitely on packet drops!

❌ 4. Parsing response.json() on 500 HTML

Crashing with json.decoder.JSONDecodeError.
Fix: Call response.raise_for_status() first!

Production Pipeline

Mini-Project: Automated Crypto Ingestion Pipeline

A robust automated market ingest pipeline fetching live Bitcoin/Ethereum prices with JSON export:

crypto_tracker.py
import requests
import json
from datetime import datetime

API_URL = "https://api.coingecko.com/api/v3/simple/price"
params = {"ids": "bitcoin,ethereum", "vs_currencies": "usd"}

response = requests.get(API_URL, params=params, timeout=5.0)
response.raise_for_status()

market_data = response.json()
snapshot = {
    "timestamp": datetime.now().isoformat(),
    "btc_usd": market_data["bitcoin"]["usd"],
    "eth_usd": market_data["ethereum"]["usd"]
}

print(f"🪙 BTC: ${snapshot['btc_usd']:,} | ETH: ${snapshot['eth_usd']:,}")

Production Pipeline Flow:

  1. 1. Safe parameter encoding via params=params.
  2. 2. Strict HTTP status code validation.
  3. 3. Timestamped JSON payload normalization.
  4. 4. Ready for downstream database insertion.
