Collection Basics

Python Lists: Ordered, Mutable & Dynamic

A list is a versatile sequence container enclosed in square brackets [ ]:

list_fundamentals.py
# 1. Homogeneous List (Same types)
scores = [95, 88, 72, 99]

# 2. Heterogeneous List (Mixed data types)
profile = ["Robiul", 25, 5.9, True]

# 3. Nested 2D Matrix List
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

print(len(scores))  # 4 elements

3 Key Properties of Lists:

  • 1. Ordered: Elements maintain their defined positional order unless sorted or modified.
  • 2. Mutable: Elements can be updated, inserted, or removed in-place without creating a new object.
  • 3. Allows Duplicates: Can hold identical values multiple times.

Methods

Essential In-Place List Methods

Modifying lists efficiently with Python's built-in array methods:

➕ Adding & Inserting

  • list.append(x): Adds single item to end O(1)
  • list.extend([a, b]): Unpacks and appends multiple items
  • list.insert(idx, x): Inserts at exact index O(N)

➖ Removing & Deleting

  • list.pop(): Removes & returns last item O(1)
  • list.remove(val): Removes first matching value
  • del list[idx] / list.clear(): Wipes elements
⚠️ Interview Gotcha: list.sort() sorts in-place and returns None! sorted(list) creates and returns a brand-new sorted list.
Internals

Memory Allocation & The Copying Bug

In Python, assigning b = a does NOT copy the list; both variables point to the same memory object!

copy_gotcha.py
original = [1, 2, 3]
alias = original  # Same pointer!

alias.append(99)
print(original)  # [1, 2, 3, 99] ⚠️ Mutated!

# Proper Independent Shallow Copy:
safe_copy = original.copy()  # or original[:]
safe_copy.append(500)
print(original)  # [1, 2, 3, 99] (Untouched!)

🧠 CPython Dynamic Over-Allocation:

When a list grows, CPython requests extra memory chunks in advance (0, 4, 8, 16, 25, 35 slots). This ensures that append() has an amortized O(1) constant time complexity.

Deep Copy for Nested Lists:

For 2D matrices, use import copy; copy.deepcopy(matrix).

Tuples

Python Tuples: Immutable Sequences ( )

Tuples are ordered collections that cannot be modified after creation:

tuple_demo.py
# Tuple creation
coords = (23.8103, 90.4125)  # Dhaka Lat/Lng

# coords[0] = 50.0  # ❌ TypeError: immutable!

# Single element tuple MUST have a comma:
single_item = ("Python",)  # tuple
not_a_tuple = ("Python")   # str!

# Elegant Tuple Unpacking
lat, lng = coords
print(f"Latitude: {lat}, Longitude: {lng}")

Why Use Tuples Over Lists?

  • 1. Data Integrity: Prevents accidental mutation of critical constants (coordinates, config settings).
  • 2. Memory & Speed: Uses less RAM and allocates faster than dynamic lists.
  • 3. Hashable: Can be used as Dictionary Keys or Set elements (lists cannot!).
Comparison

List vs. Tuple: Side-by-Side Benchmark

Choosing the right data structure for performance and architectural safety:

Feature List ([ ]) Tuple (( ))
Mutability Mutable (Editable in-place) Immutable (Write-Protected)
Memory Footprint Larger (Over-allocates memory for growth) Minimal (Exact memory allocated)
Performance Slightly slower iteration & creation Faster iteration & indexing
Dictionary Keys ❌ No (Unhashable type) ✅ Yes (Hashable if contents immutable)
Typical Use Case Dynamic data (Shopping carts, logs, queues) Fixed constants (RGB colors, DB credentials)
Pythonic Superpower

List Comprehensions: Clean & Fast

Construct new lists from iterables in a single, expressive, C-speed one-liner:

❌ Clunky Traditional Loop (5 lines):

squares = []
for n in range(1, 6):
    if n % 2 == 0:
        squares.append(n ** 2)
# Result: [4, 16]

✅ Pythonic List Comprehension:

# [expression FOR item IN iterable IF condition]
squares = [n ** 2 for n in range(1, 6) if n % 2 == 0]

print(squares)  # [4, 16]

Real-World String Sanitization:

raw_tags = [" python ", "FASTAPI ", " AI"]
clean_tags = [tag.strip().lower() for tag in raw_tags] → ["python", "fastapi", "ai"]

Applied Project

Mini-Project: Student Grade Analytics Engine

A data pipeline filtering honors students and computing statistics using lists & tuples:

grade_analytics.py
# List of Student Records (Name, Marks)
students = [
    ("Rahim", 88),
    ("Karim", 95),
    ("Ayesha", 74),
    ("Tanvir", 91),
    ("Fatima", 62)
]

marks = [mark for _, mark in students]
avg_marks = sum(marks) / len(marks)
honors = [name for name, mark in students if mark >= 90]

print(f"Class Average: {avg_marks:.2f}")
print(f"Honors Students: {honors}")

Engineering Insights:

By storing each row as an immutable tuple (name, marks) inside a dynamic list, we combine the security of tuples with the flexible sorting and filtering capabilities of lists!

📊 This matches the exact tabular data structure used in Pandas DataFrames!
