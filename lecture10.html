Foundation

Classes, Instances & The __init__ Constructor

A class is the architectural blueprint; an object is a live instance residing in memory:

bank_account.py
class BankAccount:
    # Constructor: Called automatically upon creation
    def __init__(self, owner: str, balance: float = 0.0):
        self.owner = owner          # Instance attribute
        self.balance = balance      # Instance attribute

    def deposit(self, amount: float):
        self.balance += amount
        print(f"[{self.owner}] Deposited ${amount}. New Balance: ${self.balance}")

# Instantiating distinct objects in memory
acc1 = BankAccount("Robiul", 1000.0)
acc2 = BankAccount("Ayesha", 500.0)

acc1.deposit(250)  # Only affects acc1's balance!

What is self?

self is Python's explicit pointer to the specific object instance invoking the method. When you write acc1.deposit(250), Python internally executes BankAccount.deposit(acc1, 250)!

State Architecture

Instance Attributes vs. Class Attributes

Understand where state lives: unique per object vs. shared across all instances:

attributes_demo.py
class Employee:
    # Class Attribute (Shared across EVERY instance)
    company_name = "TechNova Corp"
    total_employees = 0

    def __init__(self, name: str, role: str):
        self.name = name        # Instance attribute
        self.role = role        # Instance attribute
        Employee.total_employees += 1

e1 = Employee("Robiul", "AI Lead")
e2 = Employee("Tanvir", "DevOps")

print(e1.company_name)            # "TechNova Corp"
print(Employee.total_employees)  # 2

Comparison Matrix:

  • Instance Attribute (self.x): Defined inside __init__. Each object has its own isolated copy.
  • Class Attribute (ClassName.x): Defined directly inside class body. Stored in class namespace, shared by all.
Method Decorators

Method Types: self, @classmethod & @staticmethod

Choose the exact method signature based on the level of state access required:

method_types.py
class User:
    def __init__(self, name: str, age: int):
        self.name = name
        self.age = age

    # 1. Instance Method (Accesses self)
    def greet(self):
        return f"Hello, I am {self.name}."

    # 2. Class Method (Factory Constructor using cls)
    @classmethod
    def from_birth_year(cls, name: str, birth_year: int):
        age = 2026 - birth_year
        return cls(name, age)

    # 3. Static Method (Utility function, zero state access)
    @staticmethod
    def is_adult(age: int) -> bool:
        return age >= 18

When to Use Each:

  • Instance: Modifying individual object properties.
  • @classmethod: Alternative constructors (e.g. User.from_json()).
  • @staticmethod: Helper logic logically grouped with the class.
Data Security

Encapsulation: @property & Private Attributes

Protect internal state from invalid external mutations with clean Pythonic getters and setters:

secure_wallet.py
class SmartWallet:
    def __init__(self, initial_amount: float):
        self.__balance = initial_amount  # Private (Mangled!)

    # Getter Decorator
    @property
    def balance(self) -> float:
        return self.__balance

    # Setter Decorator with Validation
    @balance.setter
    def balance(self, value: float):
        if value < 0:
            raise ValueError("Balance cannot be negative!")
        self.__balance = value

wallet = SmartWallet(100.0)
wallet.balance = 250.0  # Clean syntax triggers setter validation!

Python Access Modifiers:

  • self.name: Public (Accessible anywhere)
  • self._name: Protected convention (Internal hint)
  • self.__name: Private (Name mangled to _Class__name)
Pitfalls

4 Common Beginner OOP Traps ⚠️

Watch out for these four frequent object-oriented bugs:

❌ 1. Forgetting self in Method

def my_method(): pass
TypeError: takes 0 positional arguments but 1 given!

❌ 2. Mutating Class Attribute on Object

obj.shared_list.append(x) # Modifies for ALL objects!
Fix: Initialize mutable lists inside __init__.

❌ 3. Direct Private Access Crash

print(obj.__secret) # AttributeError!
Fix: Use @property getter.

❌ 4. Missing @classmethod Decorator

Calling cls method without @classmethod treats first arg as instance!

Mini-Project: Secure Bank Account Vault

An enterprise banking account class encapsulating balance, audit trails, and PIN validation:

secure_account.py
class SecureAccount:
    def __init__(self, owner: str, initial_balance: float, pin: str):
        self.owner = owner
        self.__balance = initial_balance
        self.__pin = pin

    def withdraw(self, amount: float, pin: str) -> float:
        if pin != self.__pin:
            raise PermissionError("Invalid Security PIN!")
        if amount > self.__balance:
            raise ValueError("Insufficient account balance.")
        self.__balance -= amount
        return self.__balance

acc = SecureAccount("Robiul", 5000.0, "1234")
remaining = acc.withdraw(1000.0, "1234")
print(f"Remaining Funds: ${remaining}")

Encapsulation in Action:

External code cannot tamper with acc.__balance directly. Every state modification must pass through the verified business logic gates inside withdraw()!
